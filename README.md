# Public project of flatening a directory structure
The goal of this project is to create a tool capable of flatening a directory structure in a json file that will be named in the documentation flat.json.
This project was first created to facilitate web application to get access to sub-directories of a public cloud via url path.

It used json file to configurate the programs, so you will find a Markdown file for each config files to better understand how to use this program. Those markdown files will be named the same way of the config files.

The json file created by this program is a list of dictionaries that can represent either a file or a directory.
